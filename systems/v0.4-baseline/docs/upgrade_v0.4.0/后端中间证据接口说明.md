# v0.4.0 后端中间证据接口说明

## 通用约定

三模块保留原结果字段并在顶层新增：

```json
{
  "visual_evidence": {},
  "artifact_manifest": [
    {
      "id": "模块内稳定标识",
      "module": "deepfake | identity | source",
      "kind": "证据类型",
      "path": "任务目录相对/POSIX/路径",
      "sha256": "64位SHA-256",
      "size_bytes": 1,
      "status": "generated",
      "description": "证据说明"
    }
  ]
}
```

orchestrator 在三个模块完成后重新校验任务内路径、存在性、大小和 SHA-256，写入任务根 `artifact_manifest.json`。模块证据异常不会改变权威检测结果。进度事件继续写入 `logs/progress_events.jsonl` 和 `logs/progress_latest.json`，不使用模拟百分比。

## AIGC

`visual_evidence.deepfake` 包含 `face_detection`、`spatial`、`frequency`、`fusion`、`generation` 和 `native_artifacts`。

- `face_detection`：真实原始/扩展框、实际裁剪、采用人脸、224×224 输入和真实检测到的眼部候选点。
- `spatial`：6×6 Occlusion Sensitivity、纯热图、叠加图、最强响应格、耗时和基准重算误差。
- `frequency`：FFT 图、中心化频谱、32 段径向曲线、87维标准化输入、回归系数及有符号贡献。
- `fusion`：配置读取的 0.62/0.38 权重、加权分量、代入公式、阈值、差值和规范结论。

输出 12 项 manifest 证据和 13 个真实阶段事件。最终分数仍由原模型和原融合配置产生。

## 身份检索

`visual_evidence` 包含查询框/五点关键点、对齐前裁剪、112×112 标准脸、512维状态、Top-5 卡片、逐参考图聚合、Top1最佳参考图框/关键点/对齐图和并排对照。

候选在保留旧字段的基础上增加 `valid_reference_count`、`skipped_reference_count`、`reference_scores`、`skipped_reference_images`、`gap_from_top1` 和任务内 `candidate_card_image`。人员分仍是同一人员有效参考图余弦相似度的算术平均。输出 12 项 manifest 证据和 10 类真实阶段。

## 底图溯源

`visual_evidence.source` 包含 `query`、`global_stage`、`global_scoring`、`top_candidates`、`local_matching`、`fusion`。

- `query`：后端实际使用的 masked 图、检测框、屏蔽像素数和用途。
- `global_stage`：库文件数、成功读取、跳过、全局比较、Top-N、Top-K。
- `global_scoring`：HSV、灰度、边缘、外围区域四个真实分量、权重和公式。
- `local_matching`：SIFT关键点、全部 Lowe 匹配、RANSAC内点/外点、单应矩阵和投影图。
- `fusion`：未取整的全局分、局部分、0.45/0.55 权重、贡献、最终分和第一二名差值。

输出 17 项 manifest 证据和 16 类真实阶段。Lowe 0.75、RANSAC 5.0、局部分公式及排序均未改变。

## 兼容与安全

- 老结果没有新字段时仍按 v3 旧契约读取。
- 证据文件名包含输入哈希/任务命名空间，不互相覆盖。
- 正式版任务、日志、报告和缓存写入 `%LOCALAPPDATA%\FaceSourceTrace\`，安装目录只读使用。
- 正式运行路径来自 `{APP_ROOT}` 和 `{DATA_ROOT}`，不依赖开发者用户名、Torch用户缓存或开发盘符。
