# 三模块正式集成 v0.2 ChatGPT 复核包

本压缩包用于对“AI 换脸鉴伪 + 人脸身份搜索 + 原始底图搜索”正式集成进行代码、审计、测试和运行状态复核。为控制体积，压缩包不包含大型模型权重、完整身份图片库、完整底图库或 Python 虚拟环境。

目录说明：

- `01_系统说明`：README、架构、三模块、模型与发布说明；
- `02_代码`：编排、状态检查、常驻服务、三个真实 runner、UI、配置和数据库初始化关键源码；
- `03_审计`：AIGC 定位/安装版对应关系、依赖、数据库和基线完整性报告；
- `04_测试`：回归报告、自动化日志、真实成功/失败任务 JSON 与 UI 截图；
- `05_修改记录`：修改清单、原因、变更日志、已知问题及等价差异报告；
- `06_运行状态`：三个模块是否为真实模型/真实数据库的明确声明，以及环境状态快照。

复核时应特别注意：AIGC `score` 是冻结模型的 FAKE 风险分数，不是准确率或司法置信度；三模块结果只做证据汇总，没有伪造融合概率。
