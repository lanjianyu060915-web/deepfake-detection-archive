# v0.4.0 前端证据可视化升级说明

## 目标与边界

v0.4.0 将原先以长篇文字为主的结果页改造成五个证据驱动页面：研判总览、AIGC鉴伪证据、人脸身份检索、原始底图溯源、证据链与完整报告。所有分数、图片、图表和阶段均来自当前任务 JSON、进度事件或任务目录内证据文件；前端没有基准案例硬编码、随机数、固定 `sleep` 或装饰性热力图。

三个模块继续并列呈现，禁止相加。风险分数不是准确率，余弦相似度不是身份概率，底图检索分数不是来源概率；系统结论仍是侦查线索和辅助研判结果。

## 五个页面

1. **研判总览**：任务编号、输入摘要、尺寸、状态、三个模块和总耗时、设备，以及三张可跳转结果卡。完整报告不再占据总览。
2. **AIGC鉴伪证据**：原图、真实检测框/眼部候选点、实际裁剪；真实 Occlusion Sensitivity 热图和叠加图；FFT、径向频谱、真实 87 维特征有符号贡献；动态融合公式和阈值尺。
3. **人脸身份检索**：查询框、五点关键点、对齐前后人脸；Top-5 任务内参考图卡；逐参考图相似度与人员均值；跳过原因；查询与最佳参考图对照。
4. **原始底图溯源**：原图、真实检测框和后端实际 masked 图；全库漏斗；四个真实全局分量；Top-5；SIFT、Lowe、RANSAC、内外点与单应投影；局部和最终融合公式。
5. **证据链与完整报告**：任务级 artifact manifest、SHA-256、模型/输入溯源、真实事件时间线，并保留 TXT/HTML/JSON 完整报告入口。

## 实时过程

后台任务仍在单独线程执行，Streamlit 片段每 0.5 秒读取任务真实 JSONL 事件。页面通过 `st.status`、`st.progress`、实际阶段、处理计数和累计耗时刷新。阶段成功不会被误写为整个模块完成；只有模块终止事件才结束对应状态卡。

## 兼容性与失败隔离

- 老任务缺少 `visual_evidence` 或 `artifact_manifest` 时仍可加载，并明确显示“本次任务未生成该证据”。
- 切换页面只读已落盘结果，不会重新运行模型。
- 解释证据失败只降低可视化能力，不覆盖模块原始状态、分数、阈值、候选或排序。
- 所有相对证据路径必须留在任务目录，绝对候选路径必须留在批准图库；路径穿越会被拒绝。
- 图表完全离线渲染，不使用外部 CDN。
