# v0.4.0 已知限制

1. AIGC 空间图使用真实 Occlusion Sensitivity，表示模型输出敏感性，不是像素级伪造定位。正式 CPU 配置可离线运行；本机没有可用 CUDA 推理栈，因此本次不声称 GPU 通过。
2. 空间模块未配置专用五点关键点模型；AIGC 图只展示 OpenCV 实际检出的眼部候选中心，未检测到时返回空。身份模块使用 InsightFace 的真实五点关键点。
3. 身份检索是当前库内闭集排序，没有经独立验证的开放集自动拒识阈值。第一候选不能解释为身份确认。
4. 底图检索是当前库内相似候选排序，不是互联网反向搜索或来源概率。冻结算法在 203 张默认库的 CPU 单次运行约需 1.5 分钟。
5. 解释证据会增加 CPU 耗时和任务磁盘占用；失败会降级可视化，但不会改变检测分数。
6. 单次输入仅支持 JPG/JPEG/PNG/WEBP，默认上限 20 MiB；不包含视频、案件多用户管理、司法电子签章或联网检索。
7. 浏览器截图为 1280×720 比赛投屏视口的关键区截图；长页面可滚动查看全部证据，并可点击图片放大。
8. 三个模块分数定义不同，系统不生成跨模块综合概率。结果只能作为侦查线索和辅助研判材料。
