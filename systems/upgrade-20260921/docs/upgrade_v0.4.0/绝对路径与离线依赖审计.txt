换脸寻源系统 v0.4.0 绝对路径与离线依赖审计
================================================

一、审计结论

正式安装版运行时审计通过：未发现对 C:\Users\lanji、C:\Users\lanji\.cache\torch、D:\刑侦查竞赛、D:\python 或任一开发工作目录的强制运行依赖。

正式配置使用 {APP_ROOT} 解析只读程序、模型和数据库资源，使用 {DATA_ROOT}（由启动器落到 LOCALAPPDATA\FaceSourceTrace）保存任务、缓存、日志和持久服务状态。AIGC、身份检索和底图溯源所需的正式资源均随安装包提供；正式推理没有运行时下载步骤。

仓库中仍可搜索到少量个人路径或外部 URL 字符串，但均属于开发期构建默认值、历史审计文档、测试夹具、历史运行结果或训练工具说明，不会被正式安装版运行路径读取。具体分类见下文。

三、正式路径解析结果

packaging_v0.3\config.packaged.json 的关键路径全部采用占位符：

- 任务、收件箱、身份缓存和持久服务：{DATA_ROOT}/...
- AIGC Python、适配器、模型运行目录：{APP_ROOT}/...
- 身份 worker、buffalo_l 模型、身份库：{APP_ROOT}/...
- 底图 worker、203 张底图库：{APP_ROOT}/...

packaging_v0.3\static_validation.json 的最终结果为：

因此，正式配置和最终打包源中没有固定盘符路径。

四、AIGC 离线模型核验

正式空间域加载链为：

mobilenet_v3_small(weights=None)
+ 项目完整 checkpoint
+ load_state_dict(..., strict=True)

packaging_v0.3\resources\deepfake_runtime\src\detectors\spatial_mobilenet.py 的 build_model 默认 use_imagenet_pretrained=False；正式 load_verified_finetuned_model 也显式传入 False。项目 checkpoint 含完整 backbone 和 classifier，因此正式推理不需要官方 mobilenet_v3_small-047dcff4.pth。

已组装安装树中该官方 PTH 的数量为 0；这不是缺包，而是正式推理不再需要它。安装树自带并受 SHA-256 清单约束的 AIGC 资源为：

- 空间域完整 checkpoint：6,202,455 bytes；SHA-256 5BB4B33936EB3ADC631828EA271A466D62070A2B8DE1902E5D96122317534794
- 频域模型：4,129 bytes；SHA-256 2EC6828EB2A3151784667EB0C105F07CDB41DE6EC2DF587D28B2766CEEE063EB
- 融合配置：1,077 bytes；SHA-256 8F76ABEABB55DA1119B28689E15CCD31EAC7F1066E401E766987EFBB4603E0B2

代码中 MobileNet_V3_Small_Weights.DEFAULT.transforms() 只读取 torchvision 内置的预处理元数据，不下载权重。official_weights_path()/torch.hub.get_dir() 仅服务于显式 opt-in 的历史训练流程；正式推理不会调用该分支，且正式源码中没有“.cache\torch”硬编码。

五、身份检索和底图溯源离线资源

身份模块正式配置为 offline=true，model_root={APP_ROOT}/model_runtime。正式安装树提供 buffalo_l 的 5 个 ONNX 文件，总计 341,268,726 bytes；运行前 preflight_model 会先校验模型文件，缺失时直接报错，不进入 InsightFace 的模型下载路径。extractor.py 还强制设置 NO_ALBUMENTATIONS_UPDATE=1，关闭依赖导入时的 PyPI 版本检查。

身份库随包提供 45 张图片（9 人）；底图库随包提供 203 张图片。两者均从 {APP_ROOT}/data 读取，不访问开发机数据库目录。

reporting.external_language_model_enabled=false，报告生成不调用外部语言模型。

六、HTTP/HTTPS 与下载相关命中分类

正式运行路径中的 HTTP 地址仅为 127.0.0.1：

- app_launcher.py 使用 http://127.0.0.1:<port> 做 Streamlit 健康检查并打开本机页面；
- acceptance 脚本使用同类环回地址验证启动/重启。

这些是进程内本机通信，不是互联网依赖。

外部 URL 命中均不属于正式推理：

- build_release.ps1 的 https://pypi.org/simple 是开发期创建/安装 Python 环境用的可覆盖参数；
- deepfake_runtime\src\detectors\spatial_finetuning.py 和 reporting\spatial_finetune_report.py 中的 download.pytorch.org 是训练环境安装命令/报告文本；
- spatial_training.py 的 use_imagenet_pretrained=True 只用于显式训练入口，正式推理加载函数固定为 False。

正式推理源码未发现 load_state_dict_from_url、download_url_to_file 或 requests 外网请求；app_launcher.py 的 urllib.request.urlopen 目标经上下文确认仅为 127.0.0.1 健康检查。
