# 身份检索后端中间证据与回归

## 1. 算法边界

本次升级只增加结构化中间证据、任务内图像证据、完整性清单和真实进度事件。以下冻结算法没有修改：

- 模型：InsightFace `buffalo_l`；
- 查询与参考特征：512 维 `float32`，L2 归一化；
- 逐图分数：归一化向量点积，即余弦相似度；
- 人员级分数：同一人员全部有效参考图相似度的算术平均；
- 排序：人员级平均分降序，同分时按 `identity_id`；
- Top-K 截取逻辑和闭集候选语义。

身份相似度不是身份概率，第一候选只能解释为“当前身份库内第一候选”。

## 2. 结果 JSON 兼容扩展

原有 `schema_version=3.0`、`candidates[].score`、`reference_image`、`reference_count` 等字段全部保留。

候选新增字段：

- `valid_reference_count`：参与人员平均的有效参考图数；
- `skipped_reference_count`：未参与计算的参考图数；
- `best_reference_relative_path`、`best_reference_file_name`；
- `reference_scores[].reference_relative_path`、`reference_file_name`、`status=valid`；
- `skipped_reference_images[]`：路径、异常类型、真实异常消息及 `status=skipped`；
- `gap_from_top1`：第一候选人员均分减去当前候选人员均分。

顶层新增 `visual_evidence` 和 `artifact_manifest`。`visual_evidence` 包含：

- 查询人脸框、五点关键点和检测置信度；
- 查询人脸对齐前裁剪与 112×112 标准对齐状态；
- 512 维提取完成状态、L2 范数和归一化方法；
- Top-5 人员均分、最佳单图、逐参考图分数、跳过参考图及第一候选差值；
- 第一候选最佳参考图的人脸框、五点关键点、对齐图；
- 查询人脸与最佳参考人脸的并排证据；
- 最佳参考图证据重算余弦值及其与缓存分数的差值。

`artifact_manifest[]` 每项固定包含：

```text
id / kind / path / sha256 / size_bytes / status / description
```

其中 `path` 一律为任务目录相对 POSIX 路径，例如：

```text
visualizations/identity/<run_id>/query_face_detection.jpg
```

前端应以任务目录为根解析，不依赖开发机用户名或绝对安装路径。

## 3. 实际图像证据

每次成功且提供任务目录的身份搜索会旁路生成以下证据：

1. 查询原图的人脸框和五点关键点；
2. 查询人脸对齐前检测框裁剪；
3. 查询人脸 112×112 标准对齐图；
4. Top-5 每位候选最佳参考原图的任务内卡片副本；
5. 第一候选最佳参考图的人脸框和五点关键点；
6. 第一候选最佳参考图 112×112 标准对齐图；
7. 查询与第一候选最佳参考的并排对比图，不绘制虚构对应线；
8. 身份视觉证据 JSON 元数据。

对齐使用本次 InsightFace 人脸对象返回的五点关键点和 `insightface.utils.face_align.norm_crop`，不是前端估算关键点。证据生成失败只会记录 warning，不会改变已完成的分数、聚合或排序。

## 4. 参考图跳过原因

身份缓存主结构版本仍为 1，冻结 embedding 指纹和 `library_fingerprint` 不变；仅新增独立的 `diagnostics_schema_version=1`，把建库时已捕获的真实跳过原因安全写入 JSON 元数据。NPZ 仍只保存非 pickle 的 `float32` embedding。缺少诊断版本的旧缓存会安全重建一次，重建不改变评分算法或库指纹。

基准库重建确认两张未进入 43 个有效 embedding 的图片均非损坏文件：

- `person_001/06.jpg`：`MultipleFacesError`，实际检测到 2 张人脸；
- `person_002/01.jpg`：`MultipleFacesError`，实际检测到 2 张人脸。

缓存再次命中时，上述原因仍能从经过 SHA-256 校验的缓存元数据恢复，不再显示未知原因。

## 5. 真实进度事件

身份 worker 现在在实际执行位置输出以下阶段：

1. `detect_query_face`；
2. `locate_query_landmarks`；
3. `extract_identity_embedding`；
4. `load_identity_features`；
5. `compare_reference_images`；
6. `aggregate_identity_scores`；
7. `rank_identity_candidates`；
8. `align_query_face`；
9. `generate_identity_visuals`；
10. `identity_complete`。

逐参考图事件 payload 记录当前人员、参考图相对标识和本次真实余弦值；人员聚合事件记录有效参考数与 `mean` 方法。事件没有固定 `sleep`、随机数或预设候选。
