# v0.3 三模块使用与结果解释

## 1. 启动和资源检查

正式安装版从开始菜单或桌面快捷方式启动。启动器先检查正式配置、三个真实模块、模型文件、默认身份库、默认底图库、资源 SHA-256 清单和用户数据目录；全部满足后才启动本地页面。首选端口为 8767，占用时自动选择其他本地端口。

如果启动检查失败，系统不会以模拟结果继续。根据错误提示检查资源，并查看：

```text
%LOCALAPPDATA%\FaceSourceTrace\logs\launcher_v0.3.log
```

正式安装、重启和卸载验收状态：`【待最终验收回填】`。

## 2. 选择图库

页面侧栏的“本次任务身份库”和“本次任务底图库”默认指向已检查的正式资源。也可以为本次任务填写其他有权使用的图库目录：

- 身份库：根目录下每个人员一个子目录，子目录内放该人员的参考图片。
- 底图库：目录内放候选图片，可以包含子目录。
- 支持的常用格式包括 JPG、JPEG、PNG、WEBP 和 BMP；实际支持范围以页面检查提示为准。

替代图库必须存在、可读且包含可解码图片。系统只读取图库，不应改写原始图片。不要把私人照片、无授权图库或测试模拟数据混入正式资源。

## 3. 上传图片和四种操作

上传单张 JPG、JPEG、PNG 或 WEBP 图片，大小不超过 20 MiB，然后选择：

- `AI换脸/深伪风险甄别`：只运行 AIGC 模块。
- `人脸身份搜索`：只运行身份候选检索。
- `原始底图搜索`：只运行底图候选检索。
- `一键综合分析`：运行三个模块并列汇总。

未选择的模块标为 `skipped`。某一模块失败或超时时，其他已选择模块继续执行；任务可能为 `partial_success`，并仍会尝试生成部分报告。

## 4. 实时分析流程

任务开始后，页面每 0.5 秒读取任务目录中的真实事件，并显示：

- 总体状态和总体完成度；
- 当前模块、当前步骤和已运行时间；
- AIGC、身份、底图三个状态卡；
- 实际处理数量，例如“正在扫描底图库：73 / 203”和“正在几何复核：8 / 20”；
- 可展开的技术运行日志。

状态包括等待、运行中、完成、警告、失败和已跳过。能够计算的百分比来自实际阶段或处理数量；无法准确计算时显示不确定进度，不填造精确数字。进度证据写入：

```text
logs/progress_events.jsonl
logs/progress_latest.json
```

## 5. AI换脸/深伪风险结果

普通结果层展示检测结论、风险分数、判定阈值、与阈值差值，以及本次真实公式代入：

```text
0.62 × 空间域分数 + 0.38 × 频域分数 = 融合风险分数
```

融合分数高于或等于阈值时，模块输出深伪风险提示；低于阈值时，输出未检出明显深伪风险的结果。当前图片阈值为 `0.36360106194654707`，但复核时必须以本次结果 JSON 记录值为准。

技术层可展示模型名称、两个分支分数、权重、阈值、运行设备、有效人脸或帧数量、输入 SHA-256、模型与配置哈希、警告和耗时。模型没有输出眼部、皮肤或边缘等具体归因时，页面不会编造这些原因。无人脸或证据不足时，结果可为 `insufficient_evidence`，不强行形成真假判断。

风险分数是本模块模型输出，不是系统准确率或司法结论。

## 6. 人脸身份搜索结果

系统要求查询图恰好检测到一张人脸，提取 512 维 L2 归一化 embedding，与库内每张有效参考图计算余弦相似度；同一人员多张参考图取均值作为人员级分数。

结果展示：

- 当前库内第一候选和 Top-5；
- 人员级平均余弦相似度；
- 最佳参考图片和最佳单图相似度；
- 有效参考图数量；
- 第二名分数和前两名差值；
- 查询人脸数量、身份库人数、参考图片数和有效 embedding 数。

余弦相似度不是身份概率。当前没有经独立验证的开放集拒识阈值，因此结果只表示当前身份库中的相对候选顺序，不能单独用于人物身份认定。无人脸、多人脸、空库或无有效 embedding 会给出结构化原因。

## 7. 原始底图搜索结果

系统先检测并屏蔽查询图主要人脸区域，提取 HSV、灰度、边缘和外围区域等全局特征，扫描完整底图库并取 Top-20；随后用 SIFT、BFMatcher、Lowe 比率检验和 RANSAC 几何验证复核候选。

正常局部分公式：

```text
0.6 × RANSAC内点率 + 0.4 × min(RANSAC内点数 / 40, 1)
```

有效匹配不足 4 个时，冻结基线采用：

```text
min(有效匹配数 / 40, 0.15)
```

最终分公式：

```text
0.45 × 全局分 + 0.55 × 局部分
```

结果展示全局分、局部分、最终分、Lowe 筛选后的有效匹配数、RANSAC 内点数和内点率、前两名差值、查询图、人脸屏蔽图、第一候选图和匹配连线图。若查询图未检测到可屏蔽人脸，页面会说明本次按完整图像提取特征。

这些分数是当前底图库中的检索排序分数，不是来源概率，也不单独构成原始素材认定。

## 8. 完整报告和导出

每个任务完成后，系统用结构化真实结果和本地确定性模板生成：

```text
final_report.json
检测结果_<task_id>.txt
检测结果_<task_id>.html
```

页面显示“检测与检索结果已生成”，并提供：

- 查看完整报告；
- 导出 TXT 报告；
- 导出 HTML 报告；
- 在技术详情中导出 JSON 报告并查看任务结果路径。

三个格式来自同一份报告对象。HTML 可用浏览器打开和打印；本轮不要求 PDF。报告失败不会改写三个原始模块结果，错误会记录在任务状态中。

## 9. 结果保存位置

正式安装版默认保存到：

```text
%LOCALAPPDATA%\FaceSourceTrace\tasks\case_*\
```

每个任务包括查询副本、三个模块结果、统一结果、任务状态、三种报告、可视化和日志。卸载前如需迁移，请先备份整个任务目录。卸载后数据保留情况须以最终验收记录为准：`【待最终验收回填】`。

## 10. 模拟数据和正式模式

正式安装配置为 `mock_enabled=false`，普通用户入口只运行真实模块。模拟数据仅保留在源码开发测试中，必须显式开启，并始终显示“模拟数据”警告；它不能作为模型可用性、准确率或案件结论证据。

## 11. 结果边界

三个模块解决不同问题，分数所在空间不同，不能相加或转换成跨模块概率。页面和报告只并列总结：

- AIGC 模块的深伪风险证据；
- 身份模块的当前库内人员候选；
- 底图模块的当前库内素材候选。

本系统用于深度伪造风险筛查、身份候选检索和底图候选检索，仅提供侦查线索和辅助研判信息，不替代原始介质固定、哈希校验、人工复核或司法鉴定。
