# 多生成器视频训练

本轮完成七生成器的四轮训练及一轮Hunyuan对照。按dev冻结的自然配对seed43，
在固定1949条统一诊断上从33.12%改善到31.73%，但未训练生成器标签仅改善0.33个百分点，
原同域dev退化2.74点。**保留研究候选，不替换v0.1.1默认视频模型；泛化仍是主缺口。**

## 数据与方法

保持 ResNet18 `layer4+head`、四帧与`video_frames`本地接口。来源仍是Panda/HD-VILA，
七种生成器不代表七个独立来源域。

复用已登记的 ViF Panda 原包与原 train/dev：训练3,614条、dev844条，均真假各半。
按完整登记的父子、哈希、派生关系以及保守文件名分组排除旧holdout和固定ViF-Bench
关联素材，不读取holdout媒体，不把原dev移入训练。当前无新增排除，原holdout已在expanded中移除。

| 生成器 | train假视频 | dev假视频 |
| --- | ---: | ---: |
| HunyuanVideo | 309 | 73 |
| HunyuanVideo-I2V | 302 | 77 |
| CogVideoX1.5-5B-T | 301 | 65 |
| CogVideoX1.5-5B-I2V | 291 | 71 |
| Wan2.1-T2V-1.3B | 294 | 76 |
| Wan2.2-TI2V-5B-T | 169 | 32 |
| Wan2.2-TI2V-5B-I | 141 | 28 |

每个假样本保留已登记的真实父样本。全部真假采用相同2秒、16fps、448×256、
SAR1、H.264 CRF23、无音轨处理。选择2秒源于素材长度：Hunyuan仅3.375秒，
部分真实素材约2秒；不通过补帧或按类别筛选长片段制造差异。4,458条处理0失败。
这控制输出几何、时长和编码规格，不能消除原素材已有的压缩或来源差异。

比较两种采样，各跑种子42/43：一组按类别各半采样，fake的半数质量在七生成器间均分，
真实样本仍按原比例采样、generator为unknown；另一组自然shuffle，每个配对各出现一次，
保持真假内容比例一致。两组均采用BF16 AMP、batch64、AdamW主干1e-4/头1e-3，最多25 epoch、patience6。
Hunyuan对照使用原618/146样本ID、同一预处理与超参数。
每个种子只按其dev EER选epoch；按两个种子的最佳dev EER均值选择采样方案，
再在该方案中选较低dev EER的种子（方案均值相同保留生成器均衡，种子相同选42）。
自然采样对照根据训练期暴露的采样不对称性补充，未查看固定诊断分数。
冻结后才评分旧同域dev、固定全1949条3.5秒诊断及原310条CRF35诊断。

## 资源与复现

RTX4090短测重复8条实际规范化素材，只衡量资源：batch32/64分别约760/1117条每秒，
峰值allocated约0.62/1.13GiB，不计为模型质量。规范化处理耗时418.7秒。

reserved约3.15GiB。共享并发环境的耗时不能直接作为方案速度比较。
FFmpeg为`N-127271-gba987fe24d-20261010`。初次建缓存时改为4worker并行后，
在新目录重启；当时尚未开始优化，已有缓存保留，未进行optimizer/RNG训练续跑。
共同诊断采用FP32、batch64，复用帧缓存和项目评分函数。冻结候选的标准CLI
逐样本推理12/12成功，与相同batch1缓存分数完全一致；不同CUDA批量存在数值差异，
这12条CLI与batch64缓存的最大logit差为0.00336，不作为额外效果指标。
