每个视图的共同特征只提一次，供两个头复用；不增加种子、头、帧数或融合参数。

同一808条dev比较自然媒体和既有受控条件：1.25秒、448×256、16fps、20帧、CRF23，

差异不能单独归因于编解码。直接native crop对不同原分辨率的视野不同，也不是上游通用resize。
先按两批×label各2条共8条profile，再执行完整视图，profile特征复用。

旧原媒体父目录权限限制已通过仅复制dev的只读字节副本解决，原权限/所有权保持；
自然副本1,845,358,288B，受控48,142,774B，正式准备48.88秒（复用8条profile），808/808成功。
这类环境权限问题不冒充数据解码失败；真正的准备、解码、模型失败逐样本计入覆盖率分母。
