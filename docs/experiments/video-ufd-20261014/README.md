## 方法与复现

代码 `f7585e9`。作者源码固定 `030495aea3300a8b54c0ec37ec7fe1dd7e63c619`，
[来源与资源准备](../../research/pretrained-resources/README.md#universalfakedetect-视频强对照)。
原OpenAI ViT-L/14视觉权重和官方检测头转换为transformers实现，无新依赖。
完整checkpoint包含视觉编码器、768维投影与线性头，SHA-256：
`81907988948ab62e4ab20adc33f7eff6bee14f1067cf47e1e712525e0010d7f7`。
运行时只读本地tensor checkpoint，无文本编码器或隐式下载。

每个视频按原协议抽四帧，保持相同时间点；各模型保留必要空间预处理。
UFD使用作者的RGB→原尺寸CenterCrop224→CLIP mean/std，**不Resize、不做特征L2归一化**。
视频分数为帧rawlogit均值，高分更假；作者只提供图像检测，视频聚合为本项目适配。
新 `native_center_crop` 保留旋转显示与小图补边，旧模型缩放策略不变。

FP32、禁用TF32，与官方视觉模型＋检测头对齐4个实际视频/16帧：最大帧logit差
`1.24e-5`，视频差`6.68e-6`，通过`atol=rtol=1e-4`。原始结果位于
`/var/tmp/deepfake-video-ufd-20261014/author-parity.json`。没有根据诊断翻转分数方向。

```bash
scripts/devctl run python -m deepfake_detection_archive infer \
  --config docs/experiments/video-ufd-20261014/infer-canonical.json
```

另有 [旧dev配置](infer-old-dev.json)、[CRF35配置](infer-crf35.json)。它们输出到新的
`outputs/video-ufd-20261014/`，实际首轮分数在下述Git外资产中。

## 成本与决定

完整1949条样本调用耗时478.3 s，吞吐4.07视频/s；解码/预处理420.0 s，模型评分56.7 s，
冷启动38.9 s。前三组任务共享GPU，单进程阶段观察显存约1.8 GiB，无OOM。
这些是当前短视频诊断成本，不代表比赛真实万级容量；旧缓存评分时间不与之直接比较。

下一轮优先在隔离train/dev上检验冻结CLIP的小检测头适配，并使用 #51 交付的新来源开发数据
判断收益。新候选沿用相同诊断协议和已保存的对照分数，原公开头不重跑；
不因本次公开头失败而同时移植多个框架。
Effort通用图像权重作为后备，先落实权重类别与使用范围；复杂时序/人脸分支继续等待证据。
