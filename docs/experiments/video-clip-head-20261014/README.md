# 冻结 CLIP 的视频轻量头

复用 UFD 的 CLIP ViT-L/14 视觉表征，冻结骨干，仅训练现有 MLP 检测头。
按 dev 选择的 seed43 在统一1949条诊断上 EER **26.56%**，此前七生成器
ResNet 为31.73%；未训练生成器标签从33.14%改善至27.88%。保留为下一轮视频研究候选，
后续已完成[新来源受控dev比较](../video-aigvdbench-20261014/README.md)，
但母媒体独立性与正式适用许可尚未证实，不替换 v0.1.1 发布权重。

## 方法与选择

沿用七生成器的 train3,614/dev844，真假各半，原父片段、派生及确认重复组隔离不变。
全部媒体使用同一2秒、16fps、448×256、H.264 CRF23的规范化版本。
不增加训练数据，不读取 holdout 媒体，也不按历史诊断重选种子。

使用[公开 UFD 对照](../video-ufd-20261014/README.md)中已完成作者数值对齐的完整本地权重。
取原始768维投影视觉特征，不做 L2 normalization；每视频取4帧，保持作者的
native center crop、RGB及归一化。复用 `media_feature_head_v1`：LayerNorm、64维隐藏层、
dropout0.1，对帧 logits 求均值。骨干全冻结，无学习时序模型。

冻结特征以 FP32 批量提取并缓存；MLP 使用 BF16 AMP、batch128、AdamW lr1e-3、
weight decay1e-4，最多30 epoch、patience6。自然 shuffle，每个配对每 epoch 出现一次。
两个种子各按完整 dev EER 选 epoch，再按较低 dev EER 选种子，平局选42；规则与冻结记录见
[summary.json](summary.json)。选择完成后才评分三组历史诊断，均为 FP32、关闭 TF32。

| 种子 | 最佳 dev EER | 最佳 epoch | 实际 epoch | 训练秒数 |
| --- | ---: | ---: | ---: | ---: |
| 42 | 24.8815% | 17 | 23 | 38.51 |
| 43（冻结） | 24.6445% | 16 | 22 | 33.94 |

两轮均早停，optimizer 跳过更新为0。训练损失继续下降时 dev 已退化，未继续堆叠同域调参。

## 配对结果

各模型在同一条件、同一清单和标签上比较；此前模型分数直接复用。
各模型保持自身空间预处理，这是候选整体对照，不能把收益单独归因于骨干。
历史 dev 和诊断均已多次使用，不能充当未来盲测或独立来源验收。

| 条件 | v0.1.1 ResNet | 七生成器 ResNet | 公开 UFD 头 | 冻结 CLIP + MLP |
| --- | ---: | ---: | ---: | ---: |
| 选择 dev844 | 35.3081% | 30.0948% | 未评分 | **24.6445%** |
| 统一诊断1949 | 33.1165% | 31.7308% | 47.7507% | **26.5583%** |
| 已训练标签727 | 32.4238% | 29.8077% | 42.6966% | **24.0385%** |
| 未训练标签1326 | 33.4697% | 33.1424% | 50.0000% | **27.8846%** |
| CRF35匹配310 | 32.5843% | 32.1267% | 58.4270% | **25.8427%** |
| 原同域dev146 | **16.4384%** | 19.1781% | 49.3151% | 20.5479% |

三组诊断共2,405条，覆盖率均1.0、失败0。已训练/未训练标签沿用此前定义，
两者共享104条真实视频，不能把727和1326相加作为独立总样本数。
未训练标签含同家族版本；所有数据仍关联 Panda/HD-VILA 来源族，不能证明独立来源泛化。

完整19个生成器的配对摘要在 [summary.json](summary.json)。收益并非逐组一致：
相对七生成器 ResNet，CogVideoX1.5-5B-T 为17.31%→18.27%，
HunyuanVideo 为16.50%→19.42%，SkyReels-V2 为17.31%→20.19%，
Wan2.1-VACE-1.3B-T 为35.58%→37.50%。原同域 dev 也退化，保留旧对照。

## 资源与复现

代码提交 `865a2c9`；不新增依赖、训练器或检测头架构。RTX4090 实际小测
8视频/32帧 FP32 用时0.646秒，峰值 allocated1.92GB、reserved2.12GB，
采用8解码线程、32帧 batch。缓存共65.35MB（含必要 sidecar），后续 epoch 不重跑骨干。
seed42含首次准备总耗时280.33秒；seed43复用缓存总耗时51.24秒，头训练分别38.51/33.94秒。
头训练 allocated峰值约72MB，不含之前特征提取峰值；reserved保留了CUDA缓存。

标准 CLI 三组评分约4.11–4.62视频/秒，主要耗时仍是逐视频解码；多进程并行有共享负载，
这些结果不替代 #54 的离线双万级容量验收。

本目录保存实际配置、选择记录和核心摘要。完整权重、逐样本分数、缓存及必要日志位于
团队可读的 `/var/tmp/deepfake-video-clip-head-20261014/`；该路径仍属于当前实例，
持久备份由 #50 处理。冻结头位于 `seed43/training/best.pt`，SHA-256
`7dc0283f0975b2c373956e670138e4f870ed64fda78d2863183655af49037bdf`；
视觉骨干来源、版本及许可沿用 UFD 对照，正式比赛资源适用性仍未确认。
