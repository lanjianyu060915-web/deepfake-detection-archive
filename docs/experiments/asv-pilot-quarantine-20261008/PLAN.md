# ASV pilot 候选隔离系列预登记（2026-10-08）

本计划在任何 ASV 模型分数之前登记。两项音频指纹匹配仍是未确认候选；
不依据相似度将其武断排除，也不把保守连接称为已确认重复。

1. 固定原 1,024 条清单、来源、预检与两个候选的精确哈希。
2. 使用公共 `connected_groups` 在完整原清单上加入两个候选边；为所有记录写入
   有命名空间的 `derivation_group_id`，保留 group_id/identity_id/媒体哈希等原字段。
3. 按原已知关系组件隔离跨 split 候选涉及的 LA_0087 训练组件：26 条（13 真/13 假）。
   原字节不移动或删除。全集账本保留 1,024 行；隔离项 status=excluded、split=unassigned，
   原 split、排除原因和媒体字节数另存排除明细。
4. active 清单预期 998 条：train 486（243/243），dev 512（256/256）完全保留。
   保守连通统计组预期 train/dev 各 19；dev 原说话人仍为 20（real 20、fake 10），
   合并后 fake 统计组为 9。仅开发探索，不作 CI 或正式晋级结论。
5. 重新验证原全部 1,024 条实际媒体哈希、来源许可与解码状态的原证据绑定。
   使用 split=unassigned 的字节审计加独立 train/dev split 检查，无 holdout/eval 访问，
   不重解码、不重做指纹。删除样本不会增加新候选，已知候选均不得跨 active split。
6. 从冻结的四个原配置逐项核对，仅更改 manifest/feature_cache/output_dir 三处；
   sources 保持真实已登记来源路径。复用原 launcher 的监控/退出流程，修正路径与分母守卫；
   新脚本、新配置、新输出均独立且拒绝覆盖。此任务不启动训练。
7. 静态检查、实际数据断言和源哈希一致后，交 root 独立复审，之后才可安排 GPU。

许可登记中的 approved/training 指公开资源本地研究用途，不等于比赛方批准外部资源。
原 pilot/配置/预登记保持只读，新系列结果不能直接声称与原 1,024 条计划可比。
