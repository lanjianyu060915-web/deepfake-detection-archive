## 训练与选择

冻结CLIP ViT-L/14骨干，从原CLIP43的H64/dropout0.1 MLP头开始，原/新来源×real/fake等权采样。
AdamW lr1e-3、wd1e-4，batch128、BF16，max30/patience6，OMP/MKL=2。
仅以原dev844和新dev200的source macro EER选epoch，未设达标门槛；外部1880不参与选择。
本轮未设置“仅旧数据继续训练”的等预算对照，提升属于整个适配配方，不能单独归因于新增数据。

## 冻结后的外部诊断

原已见AIGVDBench dev统一受控条件、1880条，仅在两个checkpoint冻结后评分一次。
同一次FP32、TF32关闭、32帧编码批次产生共同特征，三种头以batch128输出文件级连续logit。
所有模型1044/1044选择dev、1880/1880外部dev覆盖，零解码或模型失败。
