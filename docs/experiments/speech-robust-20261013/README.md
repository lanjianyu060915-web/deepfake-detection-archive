# 语音带宽增强第二种子与白噪声增强

2026-10-13～14，RTX4090，Issue #39。
在 #29 的带宽增强 LogMel 语音候选上做两件事：补 seed43，确认带宽增强的收益是否稳定；
再只增加一组真假对称的训练期白噪声增强，看能否进一步改善跨来源表现。
模型结构、数据划分、采样、损失和带宽增强参数都不变。外部集 In-the-Wild 只对已定的候选
各评一次，不参与选择。

## 方法

新增 `augmentation.noise = {probability, min_snr_db, max_snr_db}`
（`src/deepfake_detection_archive/augmentation.py`）。命中概率时，在 [min, max] dB 内
均匀抽 SNR，按波形功率加高斯白噪声；静音波形保持不变。噪声先于带宽增强施加，
相当于“带噪录音再经过窄带信道”。增强在缓存读取之后逐条进行，缓存与评分链路不受影响。
随机门槛、SNR 和噪声种子都来自按 worker 播种的本地流，真假标签走同一策略。

| 配置 | 增强 | 种子 |
| --- | --- | --- |
| [bandwidth-seed43](bandwidth-seed43.json) | 带宽 p=0.5、8 kHz | 43 |
| [bandwidth-noise-seed42](bandwidth-noise-seed42.json) | 带宽同上 + 白噪声 p=0.5、SNR 10–30 dB | 42 |
| [bandwidth-noise-seed43](bandwidth-noise-seed43.json) | 同上 | 43 |

参照：#29 的 `bandwidth-seed42`（checkpoint `c860394c…08c3fb51`）。
三份配置与它逐字段相同，只改种子、增强、`output_dir`，以及新的波形缓存目录
（原缓存已被清理，按同一身份重建）。训练集、三个 dev 条件和 A07–A19 子集与 #29 完全一致。

## 结果

dev 和未知攻击子集的覆盖率均为 1.0，0 失败。单位：EER %。

| 条件 | 带宽 s42（参照） | 带宽 s43 | 带宽+噪声 s42 | 带宽+噪声 s43 |
| --- | ---: | ---: | ---: | ---: |
| dev clean（24,844） | 0.903 | 1.081 | 1.845 | 0.942 |
| dev AAC 64 kbps | 0.942 | 1.328 | 1.956 | 1.177 |
| dev 8 kHz 带限 | 1.386 | 1.036 | 2.002 | 0.978 |
| 三条件平均 | 1.077 | 1.148 | 1.934 | 1.032 |
| A07–A19 子集（12,000） | 2.702 | 3.563 | 4.688 | 3.462 |

按配置的双种子平均：带宽 1.113%，带宽+噪声 1.483%。

- **带宽增强稳定。** seed43 的 8 kHz 带限 1.04%，与 seed42 的 1.39% 同一量级，
  #19 无增强基线为 13.10%。clean 从 0.90% 升到 1.08%，在种子波动范围内。
- **白噪声增强不稳定，停止。** seed42 在每个条件上都明显变差，seed43 单看三条件平均
  最低。两种子差 0.9 个百分点，按配置平均也比只用带宽差，不能确认收益。
- seed43 的两次训练都跑满 30 epoch，最佳在第 28–29 轮，说明 30 轮上限可能偏紧；
  本轮不改，以保持与 #29 可比。

## In-the-Wild 外部诊断

[In-the-Wild](https://deepfake-demo.aisec.fraunhofer.de/in_the_wild) 收录 54 位公众人物的
网络语音，共 31,779 条（真 19,963 / 假 11,816）。`release_in_the_wild.zip` 的 SHA-256
`46665f30…ddf9e1a` 与作者在 HuggingFace（`mueller91/In-The-Wild`）发布的 LFS 校验一致。
`tools/prepare_in_the_wild.py` 原地登记 `test` 清单，按说话人分组；许可登记为
unresolved，仅作研究诊断。选择已在上一节按 dev 完成，这里每个候选只评一次。
本轮后 In-the-Wild 已是见过的外部诊断集，后续不能再作为未见盲测。

| 候选 | EER | 最难的说话人（EER） |
| --- | ---: | --- |
| 带宽 s42（冻结候选） | 30.67% | Frank Sinatra 84.2%、Orson Welles 68.2%、William F. Buckley 68.2% |
| 带宽 s43 | 31.19% | Nelson Mandela 82.0%、Frank Sinatra 65.8%、Bill Clinton 57.2% |
| 带宽+噪声 s42 | 27.78% | Adam Driver 87.5%、Kamala Harris 72.0%、Frank Sinatra 68.4% |
| 带宽+噪声 s43 | 50.03% | Mitch Hedberg、William F. Buckley 100%，整体无区分能力 |

所有候选在网络语音上的 EER 为 27.78%–50.03%，暴露出明显的跨来源缺口。
两个噪声种子在外部集上相差 22 个百分点，dev 最好的 s43 反而完全失效，进一步说明
这组增强不可靠。难例包括 Frank Sinatra、Orson Welles 等人物的录音；录音年代、
背景和编码差异可能影响结果，但本轮未做因素消融，不能确定失效原因。

## 结论与下一步

- **保留**带宽增强 LogMel，冻结候选维持 #29 的 seed42；seed43 作为第二种子记录在案。
- **停止**白噪声增强：dev 上没有稳定收益，外部集上种子间差异极大。
- 语音的主要缺口是真实网络语音（In-the-Wild 约 30%），不是编码或带宽退化。
  下一步需要加入许可清楚、来源独立的真实场景训练数据，而不是继续在 ASVspoof 上调增强。
  当前以统一音频接口覆盖语音、音乐和环境音，#41 的三域联合模型是主候选；
  是否引入专用模型或融合，由后续泛化收益与离线开销决定。
