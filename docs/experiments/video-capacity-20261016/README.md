## 实际执行与结果

调用现有包的`predict inputs --device cuda --output output`完整链路，
不使用预提tensor或替代评分器。测量器通过`runpy`调用包内run.py，保留CLI退出状态；
仅在结束时读取已加载Torch的allocator峰值，未修改预测实现。

使用原C seccomp launcher禁止目标及子进程新建INET/INET6 socket/socketpair，
清除外部PYTHONPATH、venv与模型包变量，包内CPython以`-I -S`运行，
HF/Torch/XDG缓存为空且结束仍无文件。该过滤条件不是恶意程序安全沙箱，
仍使用宿主FFmpeg/ffprobe、系统共享库和NVIDIA驱动。
本轮未清理OS页缓存，不能称为新机器冷启动；未迁移到独立新操作系统。
