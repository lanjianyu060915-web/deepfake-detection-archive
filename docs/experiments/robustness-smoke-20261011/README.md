## 行为验证与下一步

9项回归覆盖四条件实际解码、真假对称处理、原媒体不变、来源/组关系和ID保留、
train/holdout拒绝、失败分母、超时半文件清理、带宽退化以及立体声幅度。
独立评审发现并修复了FFmpeg恢复截断媒体后误计成功，以及AAC默认降混增加约3 dB的问题。
转码沿用项目的严格错误参数，保留源声道，不新增兼容回退或重复降混实现。

当前没有接入可用的本地候选权重，本轮**没有模型评分或EER结论**。队友交付候选后，
对相同dev样本分别运行原媒体和条件媒体推理；模型、精度、采样与聚合保持一致，复用
现有evaluate报告EER、覆盖率和分生成器退化。正式留出验收仍在候选冻结后执行。
