# DINOv2 视频表征与最后 block 适配

**保留 C10 为通用视频研究主候选，停止本轮 DINOv2 适配。**
本轮新初始化 CLIP43 在 AIGVD 已见 dev 从18.83%改善到15.86%，复现42为17.00%；
但 ViF 从25.91%退化到26.67%/26.92%，保留为研究备选，不替换发布默认。
原始 DINOv2 及最后 block 适配均明显弱于 CLIP；适配主43的 AIGVD/ViF
为24.53%/33.65%，不足以继续投入本轮训练。

本轮承接 C10 的 train5412/dev1344，比较原始 DINOv2 与 CLIP，并比较
DINOv2 最后一个 block 的适配与匹配头对照。没有新增划分或使用 holdout。
完整结果及资产标识见 [summary.json](summary.json)，实际配置见本目录的
`train-*.json`；训练由归档中的任务适配器调用现有 `train_model`，适配配置
不冒充公共 `train` CLI 配置。

## 方法

使用上游原始 DINOv2 ViT-B/14，并非 WaveRep 已适配权重。
[固定模型卡](https://github.com/facebookresearch/dinov2/blob/7764ea0f912e53c92e82eb78a2a1631e92725fc8/MODEL_CARD.md)
和 [Apache-2.0 许可](https://github.com/facebookresearch/dinov2/blob/7764ea0f912e53c92e82eb78a2a1631e92725fc8/LICENSE)
随资产保存。使用 timm 的现有权重转换，去掉预训练专用 `mask_token`，
保留 518 位置网格，通过动态位置插值处理 224 输入。真假均为 4 帧、
native center crop，DINOv2 使用 ImageNet mean/std，CLIP 使用自身归一化。
不额外归一化输出特征，视频分数为逐帧 logit 均值。

| 阶段 | 固定比较 | 共同预算与选择 |
| --- | --- | --- |
| 冻结表征 | DINOv2/CLIP，各 seed43 主、42 复现；新初始化 H64/dropout0.1 头 | 各20epoch、860updates、108280draws；batch128、AdamW lr1e-3/wd1e-4 |
| 有限适配 | DINOv2 最后 block＋末端 norm＋头，与只训头对照；各 seed43/42 | 均初始化同一个 dino43 头；各8epoch、344updates、43296draws；batch16、累积8，头lr1e-4、骨干lr1e-5/wd1e-4 |

两阶段均来源×label等权抽样，BF16 AMP，TF32 关闭；epoch 只由共同 dev 的
source macro EER 选择。seed43 在外部评分前固定为主实验，42 只作复现。
C10 expanded43 是历史对照，并非本轮新初始化的匹配 CLIP 头。
所有八个检查点冻结后才打开 AIGVD1880/ViF1949 的外部成绩。

有限适配缓存前11个 block 的完整 tokens，FP32 计算、BF16 存储，末端 FP32
评分前转回 FP32。16 条注册 train 视频的数值 profile：原视频 FP32 与未量化
prefix/suffix 最大 logit 差0；BF16 存储后平均/最大差0.00281/0.00616。
训练 BF16 suffix 相对原图 FP32 的最大差0.08409。这些路径不是 FP32 数值等价。
batch16 的一次真实前向/反向/AdamW profile 峰值 allocated 约1.09GiB。

## 结果与取舍

八组均完成共同预算，0次跳过更新。每个候选的 dev1344、AIGVD1880、ViF1949
完整分数均齐备、零失败。EER 单位为百分比，低更好；前五行用 FP32 全表征，
后四行用 BF16 存储的前缀加 FP32 末端评分，两种数值路径分别解释。

| 候选 | 旧dev844 | 新dev500 | AIGVD1880 | 去五标签1120 | ViF1949 | ViF去原训练标签1326 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 历史C10 expanded43 | 24.88 | 18.00 | 18.83 | 21.00 | 25.91 | 29.21 |
| 新CLIP43 | 24.41 | 16.25 | 15.86 | 17.83 | 26.67 | 28.97 |
| 新CLIP42 | 26.54 | 14.25 | 17.00 | 17.31 | 26.92 | 29.21 |
| 冻结DINO43 | 33.89 | 24.00 | 25.50 | 25.96 | 34.62 | 35.76 |
| 冻结DINO42 | 33.65 | 25.00 | 25.00 | 27.50 | 33.65 | 36.25 |
| DINO tuned43 | 31.99 | 24.50 | 24.53 | 26.50 | 33.65 | 34.94 |
| DINO control43 | 32.46 | 25.50 | 25.50 | 26.50 | 34.62 | 36.54 |
| DINO tuned42 | 32.23 | 25.00 | 24.69 | 27.33 | 32.69 | 34.62 |
| DINO control42 | 33.18 | 25.00 | 25.33 | 25.83 | 35.28 | 37.32 |

新 CLIP 使用相同数据从头训练轻头，与历史 C10 的继续训练初始化不同，
不能把这部分改善归因于新增数据或 DINOv2。AIGVD 的收益在第二种子同向，
ViF pooled 退化也同向；去训练标签后的收益不代表来源独立。
主43在 AIGVD 的18个生成器中16个改善、2个持平；ViF为11个改善、3个持平、5个退化。
这些分组共享真实池，不是独立重复实验。Luma/SEINE及多种 I2V 内容仍是困难方向。
DINO 微调对匹配 control 有一定改善，但没有追平 CLIP，且去五标签的主43完全持平。
下一步需要新真实来源与困难生成内容，或有实际时序表征的视频模型；
不继续扫描这些已见 dev 的种子、帧数、学习率或融合系数。

## 诊断范围与交付

AIGVD/ViF 均为已见诊断，不能证明独立来源泛化。去训练生成器标签的视图仍可能
共享来源和母媒体，不当作新盲测；每生成器沿用同一真实池。数据关系限制沿用
[C10](../video-generator-coverage-20261016/README.md)。外部成绩不用于重选种子、
早停、重训或调参数。

标准 `infer` 另对 CRF18/35 的同310个 ID 执行原视频 FP32 推理，固定比较
C10、冻结 dino43、tuned43、control43；看到外部诊断后追加新 CLIP43/42 的
描述性标准入口比较，没有再训练、调参或改选种子。该小组用来观察压缩和实际解码路径，
不能与完整 ViF1949 的 EER 直接作差。缓存评分耗时不当作端到端吞吐。

两个条件各89 real/221 fake，12组标准推理共3720/3720成功、零失败。
顺序冷进程总耗时1023.42秒，包含各次模型加载，固定batch4/reference；
不能与缓存评分或不同批量的历史容量运行作加速比较。

新CLIP在该小组CRF35有收益，DINO仍弱于CLIP；不据这个已见、事后追加的
小组推翻完整ViF结果或升级发布候选。首轮标准运行因旧CRF18媒体目录缺失而失败，
失败记录保留；已从原生成目录找回310原文件，逐项SHA与原manifest一致，
没有重编码。修复后使用新输出目录完整重跑，不复用失败分数。

冻结表征源码为 `0ddc71a`，适配与标准推理源码为 `b4ca925`，运行期间保持固定。
共享 cu126 环境、RTX4090，系统 Toolkit13.2 保持不变。完整权重包含骨干与头，
适配候选通过当前分支的 `video_frames` 标准入口加载，无需原预训练文件。
当前发布包 v0.1.1 不因本轮研究自动更新。训练数据与最终赛用许可仍待确认。
