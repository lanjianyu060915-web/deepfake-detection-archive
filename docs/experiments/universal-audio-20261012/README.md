# 三域通用音频联合训练

2026-10-13～14，RTX4090，Issue #41。
复用 AST 12层、4秒输入（`center_pad_64000_peak095_v1`），按语音/音乐/环境音以及真假采样，
一个模型同时覆盖三类音频。dev 用分域宏平均 EER 选 epoch，各域上限：语音10%、环境音5%、
音乐10%。无合格 epoch 时保留最低 macro 的研究诊断权重，并记 `selection_gate_passed=false`。
`best_dev_eer` 是所选 epoch 的 pooled EER，选模指标另记 `best_selection_metric` /
`best_selection_value`。

注册表共68,472条：train40,167 / dev28,017 / holdout288（音乐）。holdout 只保留划分元数据，
训练不读取其媒体。当前注册表每域恰有一个 source，等权配置即各域约1/3；
`joint-speech-40pct-*` 把语音提高到40%（0.4/0.3/0.3）。seed42 的运行目录保留原名
`joint-speech-down-seed42`，参数不改写。音乐只有 prompt 分组，原曲/artist 独立性未知；
music-aime96、speech-asv200 取自当前 dev，不能当作独立泛化结果。

## 冻结评分

用 v0.1.1 运行包的 `infer`（GPU）对固定桶评分，覆盖率均为 1.0、0 失败。单位：EER %。

| 桶 | 发布版 v0.1.1 | 1:1:1 s42 | 1:1:1 s43 | 0.4/0.3/0.3 s42 | 0.4/0.3/0.3 s43 |
| --- | ---: | ---: | ---: | ---: | ---: |
| urban-dev（2,885） | 1.386 | 1.603 | 1.213 | 1.213 | 1.733 |
| fsd（70） | 8.571 | 5.714 | 5.714 | 5.714 | 8.571 |
| music-aime96 | 22.50 | 0.000 | 0.000 | 0.000 | 0.000 |
| speech-asv200 | 44.00 | 0.000 | 0.000 | 0.000 | 1.000 |

联合训练把发布版在音乐、语音上的整域失效（22.50%、44.00%）降到接近 0，环境音与发布版持平。
GPU 评分 urban-dev 用 184 s，原 CPU 评分用 3,622 s。

## holdout 与外部诊断

比例和主/备选定下后，各评一次，之后不再据此调整。holdout 通过 `infer --frozen-audit` 读取。

| 集合 | 主候选 1:1:1 s42 | 备选 1:1:1 s43 | 参照 |
| --- | ---: | ---: | --- |
| fsd-holdout（70） | 8.571 | 5.714 | 首轮环境音 AST 冻结候选 11.43% |
| music-holdout（288） | 2.083 | 2.083 | — |
| In-the-Wild（31,779） | 24.856 | 19.742 | #39 LogMel 带宽 seed42 30.67% |

In-the-Wild 是 54 位公众人物的真实网络语音，见
[语音实验卡](../speech-robust-20261013/README.md#in-the-wild-外部诊断)。
联合 AST 在这类真实语音上比专门的 LogMel 语音候选好 6–11 个百分点，但仍在 20–25%，
真实网络语音依然是语音方向的主要缺口。备选在 In-the-Wild 和 fsd-holdout 上都略好于主候选，
但这两个集合只作冻结后诊断，主候选按 dev 规则确定，不据此改换；两者差异也说明单种子
结论的波动范围。

## 结论与下一步

- 三域联合训练有效：一个 AST 同时把音乐、语音的整域失效降到接近 0，环境音不退化，
  可以直接替换发布包的音频 `predict` 配置（标准 AST checkpoint+sidecar）。
- 冻结 1:1:1 seed42 为主候选、seed43 为备选。许可：ASVspoof ODC-By-1.0、
  EnvSDD CC-BY-NC（研究）、AIME 逐曲条款未决，**候选保持研究用途**。
- 早停在噪声较大的 288 条音乐 dev 上触发偏早（seed43 停在第7–8轮），下一轮可扩大音乐 dev
  或放宽 patience；同时加入真实场景语音和真实混合内容数据，In-the-Wild 只作冻结后诊断。
