# 原生 Swin3D 与 CLIP16 匹配训练

**停止本轮 Swin3D 训练，保留 C10 为通用视频研究主候选。**
原生时空模型已接通，末 stage 适配也优于匹配头对照，但仍明显弱于 CLIP：
主43 AIGVD/ViF EER 为20.94%/34.58%，匹配 CLIP16 为16.83%/26.12%。
CLIP16 相比上轮4帧 CLIP，在两个种子上都改善 ViF、退化 AIGVD，保留作研究对照，
不提升为新的主候选或发布默认。本轮没有新增数据划分、读取 holdout 或继续扫描参数。

完整单份摘要见 [summary.json](summary.json)，八份 `train-*.json` 是实际训练配置。
任务适配器调用现有 `train_model`，随 C19 保存；这些配置不冒充公共 `train` CLI 模板。

## 方法与预算

沿用 C10 train5412/dev1344，真假均16帧、224像素 `native_center_crop`。
现有受控媒体为448×256，短边已为256；该研究前端不宣称任意输入与上游 resize 相同。
Swin 使用 ImageNet mean/std，CLIP 使用自身归一化。Swin3D-T 处理完整时空片段，
池化为一个768维视频特征；CLIP ViT-L/14 为16个768维逐帧特征，头的逐帧 logit 取均值。
骨干容量和预训练来源不同，不能把全部结果差异归因于时序结构。

Swin 使用 torchvision0.29.1 `KINETICS400_V1`；原权重 SHA-256 为
`7615ae035996b65eb38dad437ae533d2dfcd36f9f89d28c0f0fa7bfb8e6b3130`。
仅移除原 Kinetics 分类头，骨干严格加载；[固定来源与许可](../../research/pretrained-resources/README.md#video-swin-原生时空表征)。
CLIP 编码器复用 C6，SHA `81907988948ab62e4ab20adc33f7eff6bee14f1067cf47e1e712525e0010d7f7`。
完整 Swin checkpoint 包含骨干与头，标准推理无需原公开权重或 prefix 缓存，不隐式下载。

| 阶段 | 固定比较 | 每组共同预算 |
| --- | --- | --- |
| 冻结表征 | Swin/CLIP 各 seed43主、42复现，新H64/dropout0.1头 | 20epoch、860updates、108240draws；batch128，AdamW lr1e-3/wd1e-4 |
| 有限适配 | Swin末stage两个blocks＋norm＋头，与只训头对照，各43/42 | 8epoch、344updates、43296draws；microbatch32/累积4，头lr1e-4/骨干lr1e-5，wd1e-4 |

全部来源×label抽样，每轮5412条；适配四组均初始化同一个 phase1 swin43 头和原公开骨干。
骨干一直保持 eval，关闭随机深度；适配组选定参数仍计算梯度，头 dropout 随训练开关。
FP32 全表征及 prefix 缓存，BF16 AMP 训练、TF32关闭；epoch 只由共同 dev source macro EER 选择。
seed43 在外部成绩前固定为主，42仅复现；八个候选完整冻结后才统一外部诊断。
历史 C17 的4帧训练为108280draws，当前为108240，历史初始化也不同，跨轮帧数比较仅描述性。

16条注册 train 视频的 profile：FP32原图与FP32 prefix 回放最大 logit 差1.34e-7，
确定 raw batch4、训练 microbatch32。实际适配峰值 allocated 为3.43GB；
并行准备/训练期间 GPU 持续运行，观察到总显存约11.2GB。
profile 大batch复用这16个输入，仅用于资源选择，不作为独立媒体或容量验收。

## 时序与原视频入口

预先固定256条dev，按source×label四桶各64条、sample_id SHA排序；三模型使用相同IDs。
比较原顺序、seed17043固定帧置乱、重复第8帧，9组共2304/2304成功、零失败。
置乱保留同一帧集合；重复帧同时减少外观覆盖，不是纯运动因果消融。

| 模型 | 原顺序EER | 置乱EER | 重复中间帧EER | 置乱平均绝对logit变化 |
| --- | ---: | ---: | ---: | ---: |
| 冻结Swin43 | 28.13% | 31.25% | 35.94% | 1.424 |
| Swin tuned43 | 25.00% | 30.47% | 31.25% | 1.751 |
| CLIP16_43 | 18.75% | 18.75% | 21.88% | 8.78e-8 |

Swin确实对时序排列敏感，CLIP均值头符合顺序不变预期；时序敏感不等于更好的鉴伪泛化。
这是已见dev的小组诊断，不据此重新选择模型或参数。三模型这部分实际评分总95.64秒，
包含各自解码，CLIP只编码一次再复用帧特征；不当作完整CLI吞吐或容量比较。

从同四桶各取2条，共8条，完整冻结Swin43、tuned43、CLIP16_43经标准 `OfflineScorer`
执行原视频推理，24/24成功、零失败。与各自FP32缓存分数的最大logit差分别为
1.91e-6、9.54e-7、2.41e-5，均小于固定1e-4容差。这仅证明加载、解码和数值链路，
不以8条小组EER评价泛化，也不重复既有万级容量或CRF验收。
