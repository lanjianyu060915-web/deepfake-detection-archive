# CLIP视频空间视图匹配训练

任务#99。高分辨率自然媒体的原尺寸224×224中心裁剪可能仅覆盖很小区域。
本轮比较原`native_center_crop`与既有`center_crop`（等比缩放后中心裁剪），
共同改变视野与纹理尺度，宽屏两侧仍裁掉，不把结果单独归因“全画面上下文”。

## 数据与固定预算

复用C10原清单`expanded-manifest.jsonl`（SHA `d9dfe6f01e444d1de362d8c45f10b877f162ed29bcc8c1d06eed92e81c710b5d`），
train5412/dev1344；沿原母媒体分组和排除，不使用首批1910平台素材训练或早停。
编码器复用C6 CLIP ViT-L/14 SHA `81907988948ab62e4ab20adc33f7eff6bee14f1067cf47e1e712525e0010d7f7`，
两组从同一C6头SHA `7dc0283f0975b2c373956e670138e4f870ed64fda78d2863183655af49037bdf`初始化。
seed43、4帧224、FP32特征/TF32关闭；batch128、源×label平衡，每epoch5414次抽样，
BF16头训练，20epochs/860updates/108280draws；仅原dev1344的source macro EER选择checkpoint。
不增加种子、帧数、融合或重新扫描旧AIGVD/ViF。

旧native特征在入口按登记字节和张量验证一次，保留原producer和sidecar，不伪装新源码重产。
新center视图独立缓存，VideoConfig进入缓存身份。研究feature头按VideoConfig取空间视图，
编码器规定尺寸/mean/std；公开完整作者检测头仍保留原native协议，标准infer复用同一特征入口。
实际特征/训练源码固定clean`69b1ec4`，独立运行副本`/var/tmp/deepfake-global-video-src/`。

## 诊断与边界

两候选按原dev选定并冻结后，各自匹配前端对原平台dev808做一次自然/受控诊断。
原native诊断特征复用#95产物，新center视图只提一次；真假处理对称，失败保留在覆盖率分母。
首批1910已因#97全量评分全部成为已见诊断，本轮不恢复盲测资格，不倒回梯度训练。
自然全长与受控首1.25秒还改变尺寸、压缩和采样，文件标签也未逐窗口核实；不能当纯codec比较。
新视图若无一致收益保留负结果，不升级C10或继续刷参数；真正晋级仍需新的无关联素材。

8条原训练样本profile成功，显存allocated峰值1,920,588,288B（约1.79GiB）。
运行配置、分数和摘要在`/var/tmp/deepfake-video-global-context-20261017/`。

自然视图8条失败（7条时间戳异常、1条无关MP2音轨错误影响严格解码），含失败的完整EER为null。
按原媒体SHA去重后自然796/804，native/global成功子集EER45.95%/44.96%；受控804/804为45.78%/49.36%。
自然的合并改善未在两批来源和受控视图中一致出现；受控两来源均退步，不能采用新视图来解决平台泛化。
逐来源、假来源配共同真实池、失败及连续分数保留在运行目录和C25；单类来源不计算EER，
复用真实池的各桶不视为相互独立的评测。

结论：保存负结果，C10仍为研究主候选，发布默认不变；停止本轮空间视图、种子、帧数和融合扫描。
下一步消费#51新的无关联训练素材，先形成可用小批，平衡真假来源/内容，再训练适配；
另取未见保留素材，首批1910不重新分配为训练或盲测。新表征也应结合新数据需求确定，不继续堆旧dev实验。
