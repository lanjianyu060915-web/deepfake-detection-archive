# [数据] 补齐通用音频与可比较的跨生成器数据

目标：解决语音不代表通用音频、视频受控集主要覆盖一个生成器的缺口。
参考文献与许可边界（`docs/research/literature.md`）；前置为云端资产/持久存储可用。

工作：

- 优先选一个许可清楚的非语音来源，以及能与现有真实视频条件匹配的生成视频来源。
  登记固定版本、来源/权重许可、原媒体/派生关系和实际内容类型，避免来源或编解码成为标签捷径。
- 给出可训练的最小数据量、实际解码覆盖和源/生成器分组划分；保持同源派生及已知身份不跨split。
- 在独立dev上形成来源/生成器留出协议；若缺少共同尺寸或只有单一来源，报告实际限制，
  不构造空集结论，也不反复扫描旧资产来代替取得新覆盖。
- EnvSDD现有530条仅辅助研究：非商用及归属边界未完成，Urban断点不是首要依赖，
  不默认把该批数据并入比赛交付候选。

交付：来源与许可登记、可复现导入配置/必要工具、实际数据统计与可用清单的团队存储位置。
一个来源能接入现有训练主线即可提交首个PR。数据许可不清楚则更换来源；不自动购买或发布数据。
大媒体不入Git，负责人审查合并。
