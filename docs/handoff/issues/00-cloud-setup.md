# [环境] 建立云端工作副本与持久资产

目标：让音频、视频队友可以在已分配的云端实例直接执行实验。参考协作说明（`docs/handoff/cloud-collaboration.md`）
和资产目录（`docs/handoff/local-assets.json`）。不新增训练框架或购买实例。

工作：

- 记录实际GPU/驱动、Python、uv、磁盘/持久卷和默认分支；使用独立工作副本。
- 用`uv.lock`同步环境，确认CUDA及FFmpeg可用，完成一次标准检查；驱动不兼容cu130时
  先选择兼容镜像，依赖变更单独PR。
- 迁入本轮状态包、ASV train/dev、ViF Panda和两套预训练权重，或从固定来源重建。
  保留数据许可与相对路径。包不含原媒体和预训练权重，Git clone也不含这些资产。
- 原媒体/权重只读；每个任务的outputs/cache独立可写，安排共用GPU占用顺序。

交付：一个环境PR，说明可执行命令、实际环境、共享资产位置/必要哈希、检查结果和未就绪资产。
必要资产可用、两项训练配置可以解析和定位输入即可完成，不要求在此Issue跑完整训练。
凭据不入Git，不自动扩容；由负责人审查合并。
