## 工程与离线验证

- 主动测试最近完整检查为 **389 passed（13.54s，无跳过）**，使用主 CUDA wheel 的
  CPU 路径；Ruff/format、32个源码及4个工具的严格 mypy 通过。独立 CPU wheel 的
  386项检查为之前阶段记录。两项归档保护和七项旧评测器 stub 不代替模型效果。
- GPU 实际前向、反向、更新、BF16和本轮真实训练通过；普通沙箱 GPU/NVML 或 IPC
  受限与 CUDA 安装失败须区分。训练保留 GNU time、温度/显存/利用率和退出证据，
  不设人为卡时上限；有价值且资源正常的实验按队列继续。
- 65个固定 CPU wheel 在断网命名空间内新建环境安装、兼容与基础CLI通过；
  主 cu130 环境未替换。见[离线安装](research/offline-rehearsal/README.md)。
- 真实 LogMel42 模型 prepare 暴露 JSON list / SourceRecord tuple 比较错误；
  原失败日志和脚本保留，新增 round-trip 正例修改前失败，修复后 **64守卫测试通过**，
  Ruff/format/严格mypy通过。新v2 stage实际断网推理/重复/中断恢复及独立只读复核通过。
  24条真实音频三套连续分数完全相同，0失败/重复/缺样；实际停止原文与前缀保留，
  SIGINT退出-2属预期。见[真实演练](research/offline-rehearsal/model-execution-20261008/README.md)，
  不等于安全屋、视频、完整集或代表500条验收。
- 远端CI、官方目标系统、500条代表性离线验收尚未完成。
