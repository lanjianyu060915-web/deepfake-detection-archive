# 压缩与重采样鲁棒性实验

日期：2026-10-11。此方向独立于队友的音频基线、视频受控基线和非语音数据接入。

目标：用同一批 dev 样本比较原媒体与转码条件下的分数和 EER，检查模型是否依赖易被压缩
或重采样破坏的信号。先完成配对媒体准备和真实媒体试跑；取得模型后再评分，不把解码通过
当作鲁棒性有效。

- 只新增 `tools/prepare_robustness.py` 和对应行为测试，复用现有清单、infer、evaluate。
  不修改训练器、编码器或队友的数据导入工具，不安装依赖，不占用 GPU。
- 输入使用已有 dev 划分，保留样本 ID、标签、来源、许可和已知组关系；原始文件只读。
  train/holdout 行不读取；条件内使用同一参数处理真假样本，不按标签选择编码强度。
- 音频比较 AAC 64 kbps，以及 8 kHz 降采样后恢复 16 kHz 的 FLAC；视频比较 H.264
  CRF 23/35，保留尺寸和时间关系，不引入音轨融合。每次显式选择条件，避免无目的全量转码。
- 每个条件保留全部所选 dev 行，准备失败写入该行及摘要，仍进入推理覆盖率分母。
  清单分条件使用，相同 ID 只用于配对；原媒体与派生媒体不得重新随机划分或合并成独立样本。
- 输出新目录中保存条件清单、必要哈希和一个简洁摘要；沿用来源登记，推理继续加载本地权重。
  工具只在外部入口校验，不新增恢复框架、兼容回退或反复全量审计。
- 完成条件：针对性行为测试、少量真实音频/视频转码与实际解码检查、独立评审、一次标准检查，
  然后在 `feat/media-robustness` 提交并推送。没有可用候选时明确保留 EER 验证缺口。
