# 历史方案评审记录

2026-10-07 的初始方案曾由独立评审检查赛题符合性、EER、数据泄漏、留出集和本地资源边界，
当时结论为可开始实施。该评审发生在小规模真实训练和离线演练之前，表格中的机械统计门、
卡时预算及“等待用户确认”等内容不再作为当前推进条件。

现行方案已根据 2026-10-08 的真实实验和用户反馈重写，入口为
[实施方案](implementation-plan.md)。当前原则是保留会影响结果真实性的数据、指标与离线边界，
删除重复证明和无收益的防御逻辑，优先扩大训练和泛化验证。

仍有效的历史结论只有：

- 内部统一 `fake=1`，连续分数越高越倾向伪造；
- 失败样本不能从 EER 分母和覆盖率中静默消失；
- 同源、派生、身份及确认的近重复组不能跨 split；
- dev 用于模型选择，冻结 holdout 只用于最终验收；
- 官方未知契约与本地研究接口分开，未知项不阻塞本地实验。

后续评审直接针对实际改动及其测试，不再维护平行的方案副本或逐项关闭证明表。
