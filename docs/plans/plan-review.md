日期：2026-10-07。对象：[implementation-plan.md](implementation-plan.md)。范围：可执行性、赛题符合性、指标/数据协议、资源与阶段边界；不是算法成绩验收。

- 最终结论：**OKAY，无已发现的阻塞问题，等待用户确认。**

## 发现与修订

| 评审问题 | 最终处理 |
| --- | --- |
| 把插值 EER 与参考最近离散交点要求总是相等 | 固定不平衡反例 0.5 vs 0.75；有精确离散交点才断言相等，ties 按手算与顺序不变性测试 |
| 失败样本没有分数却声称计算整集 EER | 无冻结合法回退时 `fullset_eer=null`，全分母报告覆盖率/失败率，成功子集只作诊断 |
| bootstrap/桶级退化和晋级条件不明确 | 配对整组重采样、有效次数/无效比例、最小组数、2 个百分点桶退化界限均明确为项目约定 |
| 最终留出被用于候选排序 | 候选及顺序在开发集冻结，最终留出只做一次审计 |
| 非语音仅在“占比显著”时覆盖 | 任一观察到的类型均需覆盖与评测，未覆盖则全音频验收不通过 |
| 8GB、数据、缓存、时长没有预算 | 给出显存/内存/数据/缓存上限、profile/pilot 和首轮卡时预算，按实测记录修订 |
| 平台未知可能阻塞全部本地工作 | 本地契约与官方差异表分开，可推进本地 P1/P2，正式 adapter/提交等待规范 |
| P1 把训练后晋级当作训练前置门 | P1 仅验数据和指标实现；P2 建立首个基线，P3 才比较晋级 |

评审同时核对了本地文档引用、3 份上游仓库 SHA、3 项已安装 skill 哈希、归档哈希及占位入口事实。定向复审确认上述问题关闭，tracked 方案与 `.omx/plans/` 本地规划副本逐字节一致。

## 保留的不确定性

官方执行契约、报名/平台权限、模型和数据授权、CUDA 可访问性、训练/推理资源及真实 EER 尚需实施阶段验证。评审通过不等于用户已经批准实施，也不等于模型有效或安全屋兼容。
