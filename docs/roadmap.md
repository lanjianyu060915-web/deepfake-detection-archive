## 当前算法取舍

- 语音保留带宽增强LogMel42；第二种子确认带限改善，白噪声未有稳定收益，停止该方案。
  In-the-Wild约30%提示跨来源缺口，优先更强表征和真实场景数据。
- 三域联合AST等权seed42为主、seed43备选，dev macro 0.70%/0.81%；已完成冻结holdout。
  未训练音乐23.6%–25.0%、真实广播混合51.3%–52.6%，不以同域接近零证明通用能力。
  保留研究候选，不据外部诊断改选或替换当前release。
- 原环境音、音乐扩展和合成混合结果保留作对照。事后分数融合未接入离线推理，是否采用
  须结合独立来源收益和实际成本；当前不新增自动路由或无条件融合。
- 冻结CLIP + 轻量头在统一1949条上26.56%、未训练标签27.88%，优于七生成器ResNet，
  原同域dev仍退化。公开UFD检测头迁移为负结果；下一投入为#51独立来源比较，
  再决定适配与时序，避免反复调同一dev，发布默认保持不变。

## 系统完成条件

1. 音频与视频都有本地可加载的已选择模型和明确适用范围。
2. 每个输入产生一个连续分数或失败记录，解码和模型失败不静默丢弃。
3. 代表性离线批量有覆盖率、耗时和资源结果；最终候选冻结后做未见holdout验收。
4. 运行包包含本地资源、依赖、配置和许可；v0.1.1按项目I/O交付，官方样例明确后适配平台格式。

工程只解决当前训练和交付问题。每轮保留配置、必要资产标识、完整分数、摘要及必要日志；
运行产物放Git外，历史通过Git追溯。相关回归先覆盖改动，提交前一轮统一检查，
没有新改动或失败就不重复测试；检查通过本身不计为算法成果。
