AIGC音视频伪造识别赛

赛题方向：大模型　　赛制：技术赛

AIGC音视频伪造识别赛题聚焦AI生成合成内容鉴别挑战，应对生成合成等技术滥用引发的信任危机。当前音视频伪造技术日趋隐蔽，严重威胁社会公信力与信息安全，亟需技术突破。赛事主办方发布包含基于最新生成合成技术制作的高质量样本集，参赛队伍需基于开源或自建数据集构建算法模型，比赛过程中，参赛队伍的算法模型需在限定时间内完成音频和视频的真伪判定，确保高效性与准确性。

比赛数据

AIGC音频检测赛：本赛题将提供约10000段音频数据，其中5000段为真实音频数据，5000段为AIGC生成音频数据，综合判断参赛者提交模型算法的识别检验能力。

AIGC视频检测赛：本赛题将提供约10000段视频数据，其中5000段为真实视频数据，5000段为AIGC生成视频数据，综合判断参赛者提交模型算法的识别检验能力。

考核指标

音视频均采用等错误率指标。

考核指标计算公式定义
等错误率等错误率（Equal Error Rate, EER）为效果评价指标，是错误接受率（FAR）和错误拒绝率（FRR）相等时的取值，即取 EER = EFAR = EFRR 时的指标来衡量系统性能。FAR 是指将非目标判别为目标造成的错误，FRR 是指将目标误识成非目标造成的错误。通过调节阈值可以使得 FAR 与 FRR 值相等，此时的 FAR 与 FRR 的值称为等错误率。EER 值越小系统性能越好。
FAR = 应被拒绝却被错误接收的伪造样本数 / 伪造样本总数 × 100%
FRR = 应被接收却被错误拒绝的真实样本数 / 真实样本总数 × 100%
综合排名分数等错误率排名分数 S1 = 比赛最优等错误率 / 实际各参赛单位等错误率 × 100%，取值范围（0,1]。
