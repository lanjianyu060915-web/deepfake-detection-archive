## 遇到的问题与处理

- 静态赛事总页未加载动态赛题正文：转向官网任务详情核验，不用“搜索不到”推断未公开。
- 默认 uv 缓存不可写：改用可写缓存，验证同步和构建；文档提供 `/tmp/aigc-uv-cache` 的用法。
- ASVspoof 参考 EER 的逐行 ties 和离散交点与拟定项目插值口径不同：在方案中明确差异，避免错误宣称两者总是相同。
- 旧清单的相对路径与 Windows 路径：原字节不改，通过归档说明解释基准，不承诺旧脚本已跨平台可运行。
- 暂存校验发现 Git 自动 CRLF 转换和未限定范围的产物忽略规则会影响历史文件：新增归档 `-text` 属性、将新产物忽略限定为根目录，并逐个核验暂存对象哈希及原文件是否入库。
