## 三模块状态

- **AIGC：真实模型，非 Demo，可用。** 使用已安装 DeepfakeDetectionSystem 的 MobileNetV3-Small 空间分支与 87 维频域统计分支，按冻结配置 `0.62 / 0.38` 融合；模型、配置、适配器及基础权重哈希均已校验。当前实际运行设备为 CPU。
- **身份搜索：真实数据库，非 Demo 库，非空，可用。** 默认库为 9 人、45 张参考图片；已生成并校验 43 个 512 维 buffalo_l embedding，另外 2 张图片未检测到可用单人脸而未进入缓存。当前实际运行设备为 CPU。
- **底图搜索：真实数据库，非 Demo 库，非空，可用。** 默认图库为 203 张图片；算法为全局手工特征与 SIFT 局部匹配的冻结检索流程。没有持久化特征/index，每次任务实时扫描。

- 当前资料中不存在可完整重建的 AIGC 原始开发仓库；接入点是安装程序内可读 PyInstaller 归档的只读冻结适配器。
- 本机虽有 NVIDIA GPU，但已验证的 AIGC 与 InsightFace 环境均为 CPU 运行栈。

- 正式版依赖本机外部 A/B Python 环境、已安装 AIGC 系统、InsightFace 模型及真实图片库；不是完全离线跨机安装包。
