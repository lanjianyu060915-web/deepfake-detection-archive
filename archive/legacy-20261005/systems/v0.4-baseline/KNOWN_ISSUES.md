# 已知问题与边界

## AIGC 上游训练工程的可追溯边界

当前工作区没有完整的上游训练仓库、训练数据和可复现训练流水线。v0.4.0 正式包已经包含经核验的 AIGC 推理源码、Python 运行时和模型资源，并通过资源清单与 SHA-256 检查；这不是安装后推理的外部依赖。该限制影响的是重新训练和训练来源复核，不影响已验收模型的本地推理。

## 本次正式验收使用 CPU

本机硬件层面的 CUDA 可用，但随包 AIGC CUDA 后端不可用，InsightFace 运行时也未启用 CUDA provider。安装后四种真实任务均在 CPU 路径成功运行，页面会如实显示实际设备。GPU 路径本次没有通过正式推理验收；若要启用 GPU，必须另行准备并验证匹配的 CUDA、PyTorch/ONNX Runtime 和驱动组合，不能只修改 UI 标签或 `device` 字符串。

## 身份搜索是闭集候选排序

系统没有经过验证的开放集拒识阈值。库外人脸仍会返回相对 Top-K，应结合相似度和人工复核，不得把 Top-1 自动解释为身份确认。默认 45 张参考图中当前 43 张形成有效 embedding；两张因不满足单人脸要求被明确跳过，不影响其余缓存就绪状态。

## 底图检索没有持久索引

冻结算法对 203 张图库逐图提取特征，安装后单模块真实任务耗时 `112.0227` 秒；耗时会随 CPU、并发、图片尺寸和磁盘性能变化。当前未添加离线特征库或 FAISS，以免改变冻结算法；默认超时为 600 秒，UI 会持续显示真实阶段。

## 正式包的资源自包含边界

v0.4.0 正式安装器包含已批准的三个模块运行时、模型和默认身份/底图库。正式入口不依赖开发机 A/B 环境、`D:\python`、Torch 用户缓存、已安装的旧 AIGC 系统或本项目开发目录；程序资源从安装目录解析，任务、报告、日志和缓存写入 `%LOCALAPPDATA%\FaceSourceTrace\`。安装后任务命令与日志中未发现开发目录或 `C:\Users\lanji\.cache\torch` 强制依赖。

该自包含范围不包括原始训练数据、完整训练流水线、互联网反向搜索服务或第三方联网数据源。离线合同已用空 `TORCH_HOME` 下的 AIGC portable、身份模块 `--offline`、正式资源本地化和前端无 CDN 合同验证；正式安装实跑没有触发下载。验收没有禁用操作系统网卡，因此不能表述为网卡级物理断网测试。

## 可视化证据的解释边界

AIGC 空间图是 Occlusion Sensitivity，表示遮挡区域对模型输出的敏感性，不是像素级伪造定位。AIGC 未配置专用五点关键点模型，相关页面只显示 OpenCV 实际检出的眼部候选中心；身份模块使用 InsightFace 的真实五点关键点。解释证据生成会增加 CPU 耗时和磁盘占用；可视化单独失败会降级展示，但不会修改权威检测分数。

## 输入与产品边界

统一 UI 当前只接入单张 JPG/JPEG/PNG/WEBP（20 MiB 上限）。没有视频入口、互联网反向搜索、案件管理、多用户队列或司法报告签名功能。底层 AIGC 运行时可能保留视频相关能力，但本系统未将其作为已集成功能。

## 结果用途

三个模块的分数定义不同，不提供跨模块融合概率。AIGC 分数是本次输入的模型风险分数，不是模型准确率；身份和底图分数分别是当前库内候选相似度。系统结果仅用于风险筛查和侦查线索，应结合原始文件、传播链、设备信息和其他证据复核。
