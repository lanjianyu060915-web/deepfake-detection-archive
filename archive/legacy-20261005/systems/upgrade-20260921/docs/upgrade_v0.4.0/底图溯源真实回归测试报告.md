## 环境差异说明

OpenCV 的 RANSAC 实现属于运行时数值依赖。使用非正式 A 环境 OpenCV 4.10 重跑时，
SIFT/Lowe 数量和全局分一致，但部分 RANSAC 内点集合与正式 worker 不同。该次运行
不作为回归验收。使用项目锁定的 B 环境 OpenCV 4.14 后，指定案例所有排序、分数和
匹配计数与既有正式 worker 完全一致。因此正式构建和验收必须继续使用锁定 B 环境，
不得混用其他 OpenCV 版本。
