本文是执行口径文档：以下写明的优先级、红线与验收标准，后续所有改动以此为准。

## 一、对提案的评审结论

### 1.1 总体判断

方向正确。六条中四条完全支持（② 开放集三态、③ 人脸预处理、⑤ 视频入口、⑥ 证据质量分级），
两条需要修正（① 二代检测器、④ 条件式局部复核）。

### 1.2 逐条结论

**① 二代检测器 —— 支持换模型，但"学习融合"不是主矛盾。**

- 实测：空间 0.4594 / 频域 0.6525 / 融合 0.62-0.38 为 0.4594 / 融合 0.5-0.5 为 0.4594。
- 结论：现融合是负贡献（受空间域拖累），但 AUC≈0.46 时任何权重组合都救不了排序能力。
  先解决"换泛化更强的检测器"，再做分数校准；不先做融合学习。
- 关键约束：工作区无上游训练数据。当下可行路径 = 零样本开源预训练检测器评测
  （CLIP 类通用检测 / NPR / LSDA 等），证明有效再集成；需要训练时另行立项数据获取。
- 红线：不得用 SWAN-DF 调参后再在 SWAN-DF 上报成绩；校准集与测试集必须分开（按换脸版本或 pair 切分）。

**② 开放集三态 —— 完全支持，第一优先级。**

- 现状：底图库外 10/10 返回自信 Top-1（0.578–0.757，库内命中区间 0.92–0.99）；身份无拒识。
- 落地：三态输出（高可信候选 / 证据不足建议人工复核 / 当前库中未发现可靠候选），
  依据分数、Top1−Top2 margin、有效参考图数、RANSAC 内点数与内点率、查询质量。
- 诚实边界：现有负样本仅 10 例库外 + 3 例身份错例，只能"演示机制"，不能"验证阈值"；
  报告需标注"初步校准、未独立验证"，并给出后续验证方案。

**③ 人脸预处理层 —— 支持，且证据充分。**

- SWAN-DF：20 查仅 10 张检出（50%），端到端 7/20；60 张参考图仅 22 张有效建库。
- 聚合消融显示"人员均值 vs 最佳单图"Top-1 一致，进一步说明瓶颈在检测/预处理，不在特征与聚合。
- 方案：多尺度检测、检测失败后的第二检测器、远景放大、参考图质量过滤；
  查询放宽为"主脸选择"时必须记录选择规则与理由，不得静默选择。

**④ 条件式局部复核 —— 支持方向，但要先证明局部复核的价值。**

- 已核实：同帧 20 例，仅全局 20/20（0.977–0.992）；加局部复核后 15/20，5 例被排错。
- 但受控 10 查询"仅全局"同样 10/10（0.99+）——现有数据中没有任何一例证明局部复核带来增益。
- 方案：先构造局部复核应当获胜的场景（裁剪、重压缩、加字幕/水印、跨帧），
  证明有效后实现"证据质量驱动的条件式复核"；证明不了则默认关闭，仅在高不确定时启用。
- 相邻帧问题：报告层按候选聚类输出"同源视频候选"，不强求精确帧级。

**⑤ 视频入口 —— 支持，且存在捷径。**

- 已核实：原生 AIGC 运行时本身支持视频（.mp4/.avi/.mov/.mkv；候选帧 ×3、最多 20 帧；
  至少 3 帧有效；保存 3 张关键帧；median 聚合；视频阈值 0.4583）。限制来自产品层。
- 分两步：AIGC 视频先通（产品/契约工作）；身份与底图再做帧选择与多帧聚合。
- 硬约束：视频任务需要新的超时与进度契约；底图逐帧在 CPU 上昂贵，必须限制关键帧数量。

**⑥ 证据质量分级而非总概率 —— 完全支持，与 ② 同批实施。**

- 用现有字段即可实现：阈值差、margin、参考图/内点数量、查询质量、拒识状态、库覆盖。
- 原则：确定性规则、公开规则表、明确"非概率"；输出研判卡/证据矩阵。

### 1.3 提案遗漏、必须补齐的四件事

1. 评估协议先于代码（数据划分、种子、bootstrap 置信区间、报告口径）。
2. 数据获取是 ① 的关键路径（零样本开源 or 公开集下载 or 自采，需明确许可）。
3. 版本与兼容策略：升级作为新版本并行构建，v0.4.0 冻结不动；schema 3.0/进度事件/报告/哈希链
   要么兼容要么显式升版；论文负结果标注"v0.4.0 结论"，改进后重跑对比。
4. 算力分工：新检测器走 GPU（本机 RTX 5060 8 GB，dev venv 已含 cu128 torch）；
   身份/底图维持 CPU；随包运行时是否带 GPU 单独决策。

## 三、评估协议（红线）

1. 数据集角色固定：
   - 校准集：用于选阈值/权重（当前候选：SWAN-DF 按版本切分的一半，或自有 145 帧验证集）；
   - 测试集：只报结果，禁止任何形式调参；
   - 开发集（10 张受控查询、案例1 同帧集）：只用于回归与演示，不得作为泛化证据。
2. 所有比较必须同输入、同环境、同超参；报告 AUC、阈值点指标、bootstrap 95% 置信区间。
3. 负结果如实保留：v0.4.0 的 0.4594 与 15/20 保留在案，升级后并列展示。
4. 每次实验写入 `experiments\<milestone>\<run_id>\`：命令、日志、输入清单 SHA-256、结果 JSON。
