# D-v2 数据收集分工建议

## 队员 1：独立 REAL

收集 100 张证据完备的原始真实图片，记录人物/场景/设备/分辨率/光照/姿态和原始文件链路；不得使用当前项目库中已经出现的内容。

## 队员 2：FAKE 方法 A/B

各准备约 34 张两种不同生成方法的 FAKE，保留工具版本、参数、生成日志、source/target 映射和输出时间；不得先让当前 baseline 运行。

## 队员 3：FAKE 方法 C

准备约 32 张第三种生成方法的 FAKE，并做与训练/开发清单的 SHA、文件名和感知哈希初筛。

## 负责人

隔离保管 Core Blind；核验许可和真值证据；排除人物/来源/内容泄漏；签署独立性说明；确保模型开发人员开考前看不到样本、标签和预测。

## 独立验收人

复核 200 条 ground truth，执行 validator 和冻结 hash。只有所有检查通过，才按正式盲测协议一次性运行。
